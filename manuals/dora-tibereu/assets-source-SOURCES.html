How DORA (2022/2554) was obtained — EUR-Lex bypass#

EUR-Lex's web frontend (eur-lex.europa.eu/legal-content/... and the /eli/.../oj paths) returns HTTP 202 with an empty body to curl/wget/WebFetch and every mirror tried (MFSA/DNB/ESMA returned 403/404). The EU Publications Office CELLAR content-negotiation endpoint is built for machine access and is not bot-protected:

curl -sSL -H "Accept: application/xhtml+xml" \
  "https://publications.europa.eu/resource/celex/32022R2554" -o cellar.html

This returns the authentic OJ XHTML (L 333/1, 27.12.2022). It was converted to DORA-Regulation-EU-2022-2554.md with scratchpad/dora/convert.py (lxml): OJ list-tables → nested Markdown bullets, article/chapter/section headings preserved, footnotes resolved by href anchor and collected as endnotes, GitHub-slug TOC generated. EU legal texts are freely reproducible (Decision 2011/833/EU). Authoritative version remains the OJ on EUR-Lex. The same CELLAR pattern fetched 2025/1190 (CELEX 32025R1190, converted with convert_rts.py, which also handles ANNEX headings and real data tables). Binding facts confirmed from the text: active red team testing ≥ 12 weeks (Art. 11(5)); the 8 Annexes specify the mandated content of each core deliverable — these are the authoritative checklists our templates map to.
