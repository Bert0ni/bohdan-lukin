TIBER-EU Engagement Knowledge Base

Reusable knowledge base, methodology and template library for delivering TIBER-EU / DORA TLPT engagements as a service provider (Threat Intelligence + Red Team, single-provider / separated-teams model).

This is a factory, not a live engagement. It holds the standards, definitions, methodologies, references, report examples and reusable skills we instantiate from on each real engagement.

Where to start#

  • New to TIBER-EU? Read reference/, then methodology/.
  • Working a phase? Open phases/.
  • Producing a deliverable? Copy from templates/.

See CLAUDE.md for the full repository map and operating rules.

Scope of our role#

We act as TIP + RT provider. We are not the Test Manager (regulator side), the Control Team (client side), or the attestation authority. We own the technical threat-led testing and its reporting under the client's and authority's governance.

Status / maintenance#

  • Normative source of truth is always the current ECB/NBS/DORA documents, not this repo.
  • Keep reference/ aligned when frameworks are revised; version significant changes.
  • Fictional examples only in examples/ — never store real client data here.
