Red Team guides library

Reusable red team manuals and guides that extend the engagement-specific red team method with general tradecraft, planning and operating practice. These are written to be lifted into engagements and refined over time.

Everything here is original content, authored for this repository and aligned to the TIBER-EU / DORA operating model (CT/TM governance, ≥12-week active phase, flags tied to CIFs, safety-first execution). Where a classic reference says it better, we cite it rather than copy it.

How this fits the engagement#

  • Plan a scenario → goal planning + threat-profile emulation → feeds the RTTP.
  • Operate safely → tradecraft &amp; OPSEC + oplog within safety &amp; risk and the RoE.
  • Evidence &amp; report → oplog → evidence register → RTTR / finding cards.
