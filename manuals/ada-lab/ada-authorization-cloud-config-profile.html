Cloud Config — Cloud Configuration (review) profile

What it is#

The Cloud Config profile assesses the security configuration of an application's cloud environment (identity & access, storage exposure, network, logging, key management, etc.), complementing the application-layer focus of CASA. It is the natural companion to a CASA AL2 engagement, whose scope already reaches deployment infrastructure and data storage.

[VERIFY] Confirm the exact Cloud Config methodology, the cloud providers in scope (AWS/Azure/GCP/others), the benchmark basis (e.g. CIS Benchmarks / provider well-architected security pillars), and its proficiency evaluation with TrustCB.

Why we add it last (profile #4)#

  • Bundles with CASA AL2 → increases average engagement value without new client acquisition.
  • Leverages existing cloud-pentest / cloud-config-review capability (IAM, metadata SSRF, storage takeover, K8s, IaC misconfig) — strong internal synergy.
  • Lowest incremental demand as a standalone profile, so it rides on CASA rather than leading.

Delivery model (to be defined from scheme docs)#

  • Read-only access / configuration export of the target cloud environment.
  • Review against the profile's control set + relevant CIS/provider benchmarks.
  • Findings + validation output per the ADA scheme.

Internal synergy#

Map our existing cloud offensive/defensive tooling and checklists to the Cloud Config control set when the methodology document is obtained — this is largely a packaging exercise over capability we already have.
