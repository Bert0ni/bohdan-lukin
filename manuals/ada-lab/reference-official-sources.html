Must-verify list (do this before budgeting/committing)#

  • TrustCB fee schedule (petition, trial evaluation per profile, annual maintenance).
  • Exact proficiency / trial-evaluation format per profile.
  • Whether a specific accreditation body is required or any ILAC-MRA signatory is accepted.
  • Current CASA requirement set + ASVS version (4.0.x vs 5.0) and count.
  • Current profile catalogue and each profile's methodology document (esp. DASA, Cloud Config — least publicly documented).
  • AL1/AL2 scope + badge mapping (e.g. Workspace Marketplace badge level).
  • Revalidation windows per profile.
  • Current authorized-lab roster (competitive scarcity).
  • Accreditation timeline + cost from the chosen body + consultant.

Source hygiene#

  • Figures in this repo tagged [VERIFY] came from secondary/vendor sources or were illustrative — replace with primary data.
