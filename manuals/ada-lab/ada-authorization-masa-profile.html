MASA — Mobile Application Security Assessment

What it is#

MASA is ADA's security assessment for mobile applications (Android & iOS). It lets developers display an "Independent security review" badge on their Google Play Data safety section and supports Play trust signals. Like CASA it is periodically revalidated.

The standard underneath: OWASP MASVS / MASTG#

MASA is based on the OWASP Mobile Application Security Verification Standard (MASVS) and the Mobile Application Security Testing Guide (MASTG). Assessment covers a defined subset of MASVS controls (historically the "MASVS-L1"-style baseline for the ADA profile). [VERIFY] the current MASA requirement set and MASTG test mapping with TrustCB.

Why MASA is our fast-follow (profile #2)#

This is a strategic synergy, not a cold start:

  • We already have a mobile security testing capability and playbooks (OWASP MASTG assessment tooling, Frida/MobSF/jadx/Burp chain, Android + iOS lessons learned).
  • The MASVS/MASTG methodology is well-documented and automatable.
  • Shared QMS, evidence pipeline and assessor pool with CASA → low marginal cost to add.

Deliverable & cadence#

An independent assessment resulting in a validation the developer can reference on Play. Validity and revalidation cadence per ADA/Play policy — [VERIFY] current validity window.
