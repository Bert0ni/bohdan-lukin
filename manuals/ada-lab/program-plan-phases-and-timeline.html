Phases & Timeline (with gates)

Windows are illustrative for a zero-ISO-17025 start — [VERIFY] against TrustCB and the accreditation body. The ISO track is the critical path; everything else parallelizes around it.

Phase detail & exit gates#

P0 — Decide & fund (Month 0)#

  • Approve business case (../strategy/investment-thesis.md); commit budget; name executive sponsor + program lead.
  • Gate: funding + sponsor committed.

P1 — Petition & foundations (Months 0–3)#

  • Submit TrustCB "Request to become an Authorized Lab"; obtain scheme docs (Security Test Lab Authorization, Scheme Overview, Evaluation Methodology).
  • [VERIFY] TrustCB fees, timeline, proficiency-eval format.
  • Select accreditation body + ISO consultant; draft scope statement.
  • Stand up the ../templates/authorization-tracker.md.
  • Gate: petition acknowledged; scheme docs in hand; accreditation body engaged; scope drafted.

P2 — Build QMS + CASA capability (Months 2–9)#

  • Build the ISO/IEC 17025 QMS (impartiality, competence, document/record control, method validation, internal audit, management review).
  • Build the CASA method as a controlled document + the evidence/automation pipeline.
  • Train and competency-record assessors; run dry-run assessments (generate QMS records).
  • Gate: QMS operational with ≥1 internal audit cycle; CASA method validated; ≥2 clean dry-runs.

P3 — Trial evaluation, CASA (Months 8–12)#

  • Perform the TrustCB-overseen trial evaluation for CASA; close any findings.
  • Gate: TrustCB trial evaluation passed.

P4 — ISO/IEC 17025 audit (Months 10–15)#

  • Accreditation body document review + witnessed assessment; remediate nonconformities.
  • Gate: accreditation granted for CASA scope.

P5 — Authorization & CASA go-live (Months 14–16)#

  • TrustCB issues authorization certificate; ADA lists the lab.
  • Launch sales + remediation-partner referral program; deliver first paid CASA engagements + Letters of Validation.
  • Gate: certificate issued, listed, first revenue booked.

P6 — Add profiles (Months 14–24)#

  • MASA (fast-follow — reuse mobile capability) → DASA → Cloud Config. Each: scope extension + profile proficiency/trial evaluation.
  • Gate per profile: trial eval passed, scope extended, first engagement delivered.

P7 — Scale & surveillance (ongoing)#

  • Grow throughput (hire to capacity targets); sustain surveillance audits and annual revalidations; track scheme/ASVS changes and re-map.
  • Gate (recurring): surveillance maintained; renewal rate on target.

Critical path & compression levers#

  • Critical path = ISO/IEC 17025 (QMS build → operating history → assessor audit).
  • Compress by: engaging an experienced consultant; deciding scope early; using dry-runs as both QMS records and trial-eval rehearsal; scheduling the witnessed audit and TrustCB trial evaluation close together.
