Market Sizing — TAM / SAM / SOM

Method note. No public figure exists for the number of CASA/MASA-obligated apps, so this is a transparent bottom-up model with explicitly flagged assumptions. Every ASSUMPTION is a dial you can change. Confirmed anchors: the requirement is real, annual, lab-only (Google no longer accepts self-scans for restricted scopes) and pricing is mapped in competitor-pricing.md. Replace assumptions with sourced data before investor use.

What creates an obligated app (the demand trigger — confirmed)#

  • Google CASA: apps using sensitive/restricted OAuth scopes (Gmail, Drive, Calendar, Workspace) with a meaningful user base must complete an annual CASA assessment by an authorized lab. Restricted scopes + higher risk → AL2; sensitive → AL1.
  • Google MASA: Android apps seeking the Play "independent security review" badge.
  • Both recur annually → the installed base compounds.

SAM — Serviceable Addressable Market#

The slice we can realistically serve given language, region, profile scope and positioning:

  • Profiles we'll offer: CASA + MASA first (then DASA, Cloud Config, AI Agents).
  • Positioning: automation-first, competitive AL1, strong AL2, EN+UA+CEE/EU reach.
  • SAM assumption: ~20–25% of core TAM is realistically serviceable by a mid-tier, automation-led lab → ~$30–45M/yr.

SOM — Serviceable Obtainable Market (our 3–5 yr capture)#

Capture is supply-constrained, not demand-constrained — only ~10 labs exist, so the binding limit is how many assessments we can staff, not whether demand exists (see the capacity model in financial-model.md).

Guardrail (per the brief): do not assume authorization yields referrals from Google/ Meta/Microsoft, and do not book Microsoft/Meta as ADA-lab revenue. They widen the narrative TAM and create cross-sell potential (one app often needs several), but the bankable base is Google CASA + MASA.

Demand tailwinds (why the obligated base grows)#

  1. AI agents/LLM tools requesting Google scopes — a net-new, fast-growing obligated cohort (see ../ada-authorization/ai-agents-profile.md).
  2. Tightening enforcement — self-scans disallowed; lab assessment mandatory for restricted scopes → forced migration to authorized labs.
  3. Annual revalidation — the base never resets; it accumulates.
  4. Procurement spillover — CASA/MASA badges used as trust signals beyond the strict mandate.
